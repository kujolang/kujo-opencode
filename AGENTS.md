# Kujo OpenCode

Keep the host adapter thin. Product logic belongs to canonical Kujo tools and
Ability definitions. Do not proxy inference or spoof model-provider clients.
Run npm test and the real local E2E gate for executor or host changes.
Use npm run test:opencode against a configured isolated project for host checks.
Preserve the upstream runtime digest and explicit host transformation provenance.
Never auto-approve a write, delete, or external Ability. Keep all host effects
and optional installation requirements explicit. No background telemetry by default.
