## Fixes

MCP now uses native filesystem joins and creates directories by walking existing
ancestors. The regression generates nested output twice, validates resource paths
and runs the generated server's self-check. The source pin is
`90f264f55274a99e0ca0aba079e1c94fd024552d`; its
[Windows regression run](https://github.com/kujolang/mcp/actions/runs/39050211266)
passed. The full local MCP suite passed too.

Kennel now uses native manifest, lockfile and installation paths. Git receives
arguments directly, with Windows verbatim prefixes adapted only at the external
Git boundary. Canonical filesystem checks retain their native paths. The tested
pin, `5f67d348a256dae7876c15e106fd1d72b04e7df0`, builds on the prior OpenCode pin
`92326c4bc11377ffa9fedf51d8c3ad3e7575e02b`; it preserves that baseline's newer
behavior. [Native installation CI](https://github.com/kujolang/kennel/actions/runs/39051623262)
passed Windows and Linux. Local core and security suites passed. This proves the
project dependency-install path; it does not expand Kennel's global installer
support claim to Windows.

The native host test now reuses the location object returned by OpenCode when
creating ledger sessions. It also verifies that this location resolves to the
owned fixture directory. Constructing a second location from Node's Windows
path representation left the approval receipt in place but the tested session's
permission list empty. Extending the wait alone did not fix it. Reusing the host
identity passed both native and rendered checks in
[diagnostic run 39051279105](https://github.com/kujolang/kujo-opencode/actions/runs/39051279105),
then passed the final matrix. Approval rules and rejection assertions remain intact.

OpenCode's local unit suite passed all 237 tests, and the local end-to-end suite
passed. Earlier failed runs remain evidence, not passing results: the first new
matrix (`39050490665`) exposed Kennel after MCP was fixed; ledger diagnostics
`39049980448`, `39050323522` and `39050849455` narrowed the location issue.
An intermediate Kennel pin was rejected before acceptance because it came from
an older local branch; the final pin applies only the Windows changes to the
existing baseline.
